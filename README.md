# 🏢 TrackMyRent (RentTrack) — പ്രോജക്റ്റ് പൂർത്തീകരണ ഗൈഡ് & ആർക്കിടെക്ചർ (Project Roadmap)

**TrackMyRent** എന്നത് ജിമ്മുകൾ (Gyms), ട്യൂഷൻ സെന്ററുകൾ (Tuition Centers), അക്കാദമികൾ (Academies), ഹോസ്റ്റലുകൾ/പി.ജി (Hostels/PG), വാടക കെട്ടിടങ്ങൾ (Rental Buildings) എന്നിവ നടത്തുന്ന **ഫെസിലിറ്റി അഡ്മിൻമാർക്ക് (Facility Admins)** അവരുടെ മെമ്പർമാരെയും, ബാച്ചുകളെയും, വാടക കുടിശ്ശികകളെയും, ദൈനംദിന ചെലവുകളെയും ഡിജിറ്റലായി കൈകാര്യം ചെയ്യാൻ സഹായിക്കുന്ന **മൊബൈൽ-ഫസ്റ്റ് (Mobile-First) മാനേജ്‌മെന്റ് സിസ്റ്റമാണ്**.

## 📌 1. നിലവിലെ പ്രോജക്റ്റ് സ്റ്റാറ്റസ് (Current Status - Completed Modules)

ഇതുവരെ പൂർത്തിയാക്കിയ പ്രധാന മൊഡ്യൂളുകൾ:

| മൊഡ്യൂൾ | വിവരണം | സ്റ്റാറ്റസ് |
|---|---|---|
| **Facility Admin Auth** | മൊബൈൽ നമ്പർ OTP ലോഗിനും ആദ്യ രജിസ്ട്രേഷനും (`00000` ഡെമോ ലോഗിൻ സഹിതം) | ✅ പൂർത്തിയായി |
| **Plan & Group Hierarchy** | പ്ലാനുകൾ (Plans) $\rightarrow$ ബാച്ചുകൾ/ഗ്രൂപ്പുകൾ (Groups) $\rightarrow$ മെമ്പർമാർ ഘടന | ✅ പൂർത്തിയായി |
| **Member Engine** | മെമ്പർ അഡ്മിഷൻ, പ്ലാൻ/ബാച്ച് അസൈൻമെന്റ്, ഓട്ടോമാറ്റിക് ഡ്യൂ ഡേറ്റ് കാൽക്കുലേഷൻ | ✅ പൂർത്തിയായി |
| **Dynamic Custom Fields** | ആധാർ, ബ്ലഡ് ഗ്രൂപ്പ്, എമർജൻസി നമ്പർ തുടങ്ങിയ ഏത് കസ്റ്റം ഫീൽഡുകളും ആഡ് ചെയ്യാനുള്ള സൗകര്യം | ✅ പൂർത്തിയായി |
| **Payment Schedules & Freeze** | ഓരോ മാസത്തെയും വാടക നില, മാസം ഫ്രീസ് ചെയ്യൽ (Freeze ❄️), അൺഫ്രീസ് ചെയ്യൽ | ✅ പൂർത്തിയായി |
| **Expense Tracker** | കസ്റ്റം കാറ്റഗറികൾ സഹിതമുള്ള ദൈനംദിന ചെലവുകളുടെ ട്രാക്കിംഗും കാറ്റഗറി ബ്രേക്ക്ഡൗണും | ✅ പൂർത്തിയായി |
| **Financial Analytics** | Collection Rate സൂത്രവാക്യം, വരുമാനം, ചെലവ്, ലാഭം, കുടിശ്ശിക അനലിറ്റിക്സ് | ✅ പൂർത്തിയായി |
| **Admin Web Dashboard** | ഫെസിലിറ്റികളെ നിരീക്ഷിക്കാനുള്ള സൂപ്പർ അഡ്മിൻ വെബ് പോർട്ടൽ (Next.js 14) | ✅ പൂർത്തിയായി |

## 🎯 2. പ്രോജക്റ്റ് 100% പൂർത്തിയാക്കാൻ ഇനി ആവശ്യമുള്ള കാര്യങ്ങൾ (To-Do for 100% Completion)

പ്രോജക്റ്റ് ലൈവ് ആക്കുന്നതിനായി (Production Deployment) താഴെ പറയുന്ന 4 കാര്യങ്ങളാണ് പൂർത്തിയാക്കേണ്ടത്:

### ① Razorpay ലൈവ് പേയ്‌മെന്റ് ഗേറ്റ്‌വേ ഇന്റഗ്രേഷൻ (Razorpay Live Integration)
- [ ] **Razorpay Account Credentials**: അഡ്മിന്റെ `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET` എന്നിവ ബാക്കെൻഡ് `.env`-ൽ ചേർക്കുക.
- [ ] **Payment Link API**: കുടിശ്ശികയുള്ള തുകയ്ക്ക് തനിയെ ലിങ്ക് (`https://rzp.io/i/...`) നിർമ്മിക്കുന്ന എൻഡ്പോയിന്റ് സജീവമാക്കുക.
- [ ] **Razorpay Webhook**: കസ്റ്റമർ ഗൂഗിൾപേ/ഫോൺപേ വഴി പണമടച്ചാൽ ബാക്കെൻഡിലേക്ക് വരുന്ന `payment_link.paid` ഇവന്റ് സ്വീകരിച്ച് ആപ്പിൽ ആ മാസത്തെ വാടക **`PAID`** ആയി മാറ്റുന്ന വെബ്ഹൂക്ക് സെറ്റപ്പ് ചെയ്യുക.

### ② Meta WhatsApp Cloud API ലൈവ് കോൺഫിഗറേഷൻ (WhatsApp Cloud API Integration)
- [ ] **Meta Developer Portal**: WhatsApp Business അക്കൗണ്ട് തുടങ്ങി Phone Number ID, WABA ID, Permanent Access Token എന്നിവ ലഭ്യമാക്കുക.
- [ ] **Automatic Credit Deduction**: ആപ്പിൽ നിന്ന് ഓരോ ഓട്ടോമാറ്റിക് വാട്സാപ്പ് മെസ്സേജ് അയക്കുമ്പോഴും അഡ്മിന്റെ വാലറ്റിൽ നിന്ന് 1 ക്രെഡിറ്റ് കുറയ്ക്കൽ.
- [ ] **1-Tap WhatsApp Direct Fallback**: വാട്സാപ്പ് എപിഐ ഇല്ലാത്തപ്പോഴും അഡ്മിന് സ്വന്തം ഫോണിലെ വാട്സാപ്പ് തുറന്ന് പ്രീ-ഫിൽ ചെയ്ത ലിങ്ക് സഹിതം ഒറ്റ ക്ലിക്കിൽ അയക്കാനുള്ള സൗകര്യം നിലനിർത്തുക.

### ③ ഓട്ടോമേറ്റഡ് ഷെഡ്യൂളർ / ക്രോൺ ജോബ് (Automated Monthly Cron Jobs)
- [ ] **Monthly Bill Generation**: എല്ലാ മാസവും ഒന്നാം തീയതി ആക്ടീവ് മെമ്പർമാർക്ക് പുതിയ മാസത്തെ പേയ്‌മെന്റ് ഷെഡ്യൂൾ ഓട്ടോമാറ്റിക്കായി ക്രിയേറ്റ് ചെയ്യുക.
- [ ] **Auto WhatsApp Reminder**: വാടക ഡ്യൂ ആകുന്നതിന് 2 ദിവസം മുൻപും, ഡ്യൂ ദിവസവും രാവിലെയുള്ള ഓട്ടോമാറ്റിക് വാട്സാപ്പ് റിമൈൻഡർ ഷെഡ്യൂൾ ചെയ്യുക.

### ④ PDF ഇൻവോയ്സ് & രസീത് ഡൗൺലോഡ് (PDF Receipt Generation)
- [ ] മെമ്പർമാർ വാടക അടച്ചു കഴിയുമ്പോൾ ഡൗൺലോഡ് ചെയ്യാവുന്ന തരത്തിൽ ഔദ്യോഗിക QR കോഡും സ്റ്റാമ്പും ഉള്ള പിഡിഎഫ് രസീത് തയ്യാറാക്കൽ.

```env
# Database
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/renttrack_db?schema=public"

# Server
PORT=5001
JWT_SECRET="your_super_secret_jwt_key_here"

# Razorpay Live / Test Credentials
RAZORPAY_KEY_ID="rzp_test_xxxxxx"
RAZORPAY_KEY_SECRET="your_razorpay_secret"
RAZORPAY_WEBHOOK_SECRET="your_webhook_secret"

# Meta WhatsApp Cloud API Credentials
WHATSAPP_PHONE_NUMBER_ID="your_phone_number_id"
WHATSAPP_BUSINESS_ACCOUNT_ID="your_waba_id"
WHATSAPP_ACCESS_TOKEN="your_permanent_meta_access_token"
```

## 🚀 5. പ്രോജക്റ്റ് ലോക്കലായി റൺ ചെയ്യാനുള്ള കമാൻഡുകൾ (How to Run)

1. **ബാക്കെൻഡ് ആരംഭിക്കാൻ**:
   ```bash
   cd backend
   npm install
   npm run dev
   ```
2. **മൊബൈൽ ആപ്പ് ആരംഭിക്കാൻ**:
   ```bash
   cd mobile_app
   flutter pub get
   flutter run
   ```
3. **അഡ്മിൻ വെബ് പോർട്ടൽ ആരംഭിക്കാൻ**:
   ```bash
   cd admin-web
   npm install
   npm run dev
   ```
